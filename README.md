# 튜브 벤딩 마킹 계산기 · 앱 설치 방법

## 방법 1. 홈 화면 앱 (아이폰·안드로이드 둘 다, 5분)

1. github.com 에서 새 저장소 만들기 (예: `bend-calc`, Public)
2. 이 압축 파일 안의 파일을 **폴더 구조 그대로** 업로드 (`.github` 폴더 포함)
   - 웹 업로드에서 `.github` 폴더가 안 보이면 PC에서 "숨김 파일 표시"를 켜고 끌어다 놓기
3. 저장소 **Settings → Pages → Source** 를 **GitHub Actions** 로 변경
4. **Actions** 탭에서 "웹앱 배포" 가 초록색으로 끝나면 주소가 생김
   `https://<아이디>.github.io/bend-calc/`
5. 폰에서 그 주소 열기
   - 안드로이드(크롬): 메뉴 ⋮ → **홈 화면에 추가 / 앱 설치**
   - 아이폰(사파리): 공유 버튼 → **홈 화면에 추가**

한 번 열어 두면 데이터가 안 터지는 곳에서도 열립니다. 팀원에게는 주소만 카톡으로 보내면 됩니다.

## 방법 2. 안드로이드 APK 파일

위 1~2번을 하면 Actions 탭에서 **"Android APK 빌드"** 도 자동으로 돌아갑니다 (약 5분).

1. Actions → Android APK 빌드 → 완료된 실행 클릭
2. 아래 **Artifacts** 의 `bending-marking-apk` 다운로드 → 압축 풀면 `app-debug.apk`
3. 폰으로 옮겨 설치 ("출처를 알 수 없는 앱 허용" 필요)

> 테스트용(debug) APK 입니다. 플레이스토어 등록용은 서명 키를 만들어 release 빌드가 필요합니다.

## 수정할 때

`www/index.html` 만 고쳐서 다시 올리면 웹앱과 APK가 둘 다 자동으로 다시 만들어집니다.
